# Rock, Paper, KO! — serveur relais

Petit serveur WebSocket qui met deux joueurs en relation avec un code de 4 lettres,
puis transmet leurs choix. Le combat est calculé sur chaque téléphone (même graine de hasard).

Hébergement : Render (Web Service, Node, offre gratuite).
- Build command : `npm install`
- Start command : `node server.js`
